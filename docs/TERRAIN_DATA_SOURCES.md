# PRE-STEP 02-A DEM
선정: Copernicus GLO-90 (현대 DSM, 약 90m, WGS84 / EGM2008 m). 실제 취득 실패: DNS. 원본 크기/고도/취득일 미확정. 9개 타일 URL은 prepare_dem.py에서 생성한다. 예: https://copernicus-dem-90m.s3.eu-central-1.amazonaws.com/Copernicus_DSM_COG_30_N33_00_E112_00_DEM/Copernicus_DSM_COG_30_N33_00_E112_00_DEM.tif (개별 URL 미검증).
출처 및 라이선스: https://registry.opendata.aws/copernicus-dem/ ; https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM ; https://dataspace.copernicus.eu/sites/default/files/media/files/2025-06/copernicus_contributing_mission_data_access_v2_cop_dem_licenses.pdf . 공개 재배포 전 이용조건 확인/수락 및 출처 표시 필요. 가공물에는 produced using Copernicus WorldDEM-90 © DLR e.V. 2010-2014 and © Airbus Defence and Space GmbH 2014-2018 provided under COPERNICUS by the European Union and ESA; all rights reserved 표시.
범위 원안 유지. 북쪽 -Z, 동쪽 +X. 중심 위도 기준 등거리 근사 투영, 정밀 측지 아님. 129/257/513 float32 LE, 북→남 행, 서→동 열, 양 끝 좌표 포함. 결측 발견 시 중단. 마커 좌표는 검증 전 대략적인 현대 지명 및 호뢰관 일대 위치이며 역사 위치 확정 아님.
## 설치 없는 데이터 취득 방법
먼저 라이선스 확인 후 업데이트 파일을 저장소 루트에 올린다. Actions → Prepare actual DEM → Run workflow → main. 성공한 실행의 Artifacts에서 henan-central ZIP 다운로드, 압축 해제 후 metadata.json 및 세 f32 파일을 public/assets/terrain/henan-central/에 업로드하고 commit. 기존 Pages workflow가 배포한다. 실패하면 로그 전달. 이 워크플로는 현재 실행 미검증. 원본 보존이 필요하면 Python 스크립트를 별도 실행하고 dem-cache를 보관한다. 플레이 시 Python/Node 불필요.

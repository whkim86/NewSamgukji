# 신(新) 삼국지 WEB
## Codex 통합 개발 인수인계 및 최종 안정화 지시서 V3.0

## 1. 프로젝트 개요

- 프로젝트명: NewSamgukji
- 현재 버전: v0.5.0-dev.2 최신 개선본
- 최종 목표 버전: v0.5.0
- 현재 프로젝트 규모: 73개 파일
- 누적 자동 테스트: 28/28 통과 보고
- 정식 엔진: Three.js
- 웹 빌드: Vite
- 배포: GitHub Actions + GitHub Pages
- 개발 방식: 기존 프로젝트 기반 증분 자율 개발

GitHub Repository:
https://github.com/whkim86/NewSamgukji

웹 실행 주소:
https://whkim86.github.io/NewSamgukji/

본 프로젝트는 기존 ChatGPT 개발 환경에서 개발되었으며, 반복적인 DNS 오류, npm 의존성 설치 실패, Chromium EGL 오류 등으로 실제 통합 빌드 및 브라우저 검증을 완료하지 못했다.

이번 작업부터 Codex 개발 환경에서 기존 프로젝트를 인수하여 실제 실행 및 검증을 완료한다.

## 2. 최종 게임 개발 방향

삼국지 III의 전략 및 내정 시스템, 삼국지 XI의 통합 지형 지도, 삼국지 XII의 실시간 전투 및 Total War 계열의 시각적 표현을 참고한 독립적인 삼국지 전략 RPG 게임을 개발한다.

최종 목표:

- 실제 중국 지리 기반 통합 월드
- 실제 거리 기반 군대 행군
- 지형별 이동 속도 및 이동 비용
- 별도의 전투 화면으로 전환하지 않는 실시간 전투
- 중국 전체 지도부터 개별 병사까지 연속 확대
- 도시, 주민, 장수, 병사 및 군대 표현
- 200개 이상의 거점으로 확장 가능한 구조
- 1,000명 이상의 장수로 확장 가능한 구조
- 웹 기반 개발 후 Windows EXE 확장 검토

이번 개발 범위는 정식 게임 시스템 개발 전 기술 기반 완성까지다.

## 4. 개발 운영 원칙

- 기존 프로젝트를 처음부터 다시 작성하지 않는다.
- 기존 코드와 데이터를 보존한다.
- 기존 테스트를 임의로 삭제하지 않는다.
- 사용자 중간 수동 테스트를 요청하지 않는다.
- 단계별 사용자 승인 없이 순차 개발한다.
- 일반적인 기술적 결정은 Codex가 자체 판단한다.
- 기존 기능의 오류를 발견하면 자체 수정한다.
- 각 작업 완료 후 누적 보고서를 갱신한다.
- 실제 수행하지 않은 개발 및 테스트를 완료 처리하지 않는다.
- 유료 결제, 외부 계정 인증, 복구 불가능한 변경 등은 사용자 확인 후 진행한다.

기존 V2.0 및 V2.1 지시서가 프로젝트 내에 존재하는 경우 참고한다.
